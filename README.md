# AICE Associate Study

AICE Associate 스터디 실습코드 저장소입니다.

## 한눈에 보기

매주 실습한 코드(.ipynb 파일)를 이 저장소에 올려 주세요. 올릴 곳은 **그 주차의 브랜치 안, 내 이름 폴더**예요. 예를 들어 1주차 실습은 `week1` 브랜치의 `선준` 폴더에 올리면 돼요.

- 프로그램 설치는 필요 없어요. 웹 브라우저에서 파일을 끌어다 놓기만 하면 돼요.
- 처음 한 번만 GitHub 가입과 초대 수락이 필요해요.

## 알아두면 좋은 용어 5개

어렵게 생각하지 않아도 돼요. 아래 정도만 알면 충분해요.

| 용어 | 뜻 | 비유 |
| --- | --- | --- |
| Git | 파일의 변경 기록을 관리하는 도구 | 문서의 '버전 기록' |
| GitHub | Git으로 관리하는 파일을 올려두는 웹사이트 | 코드용 구글 드라이브 |
| 저장소 (Repository, 레포) | 프로젝트 하나의 파일을 모아두는 곳 | 스터디 공용 폴더 |
| 브랜치 (Branch) | 같은 저장소 안의 독립된 작업 공간 | 주차별 칸막이 (week1, week2 …) |
| 커밋 (Commit) | 변경 사항을 저장 확정하는 것 | '저장' 버튼 |

저장소 구조는 이렇게 생겼어요. 브랜치마다 멤버 폴더 5개가 똑같이 들어 있어요.

```
AICE-associate-study
├─ main     ← 기본 브랜치 (여기엔 올리지 않아요)
├─ week1    ← 1주차
│   ├─ 선준/week1.ipynb
│   ├─ 승현/week1.ipynb
│   ├─ 예지/ · 은규/ · 제이/
├─ week2    ← 2주차
└─ …
```

## 처음 한 번만 하면 되는 준비

저장소에 파일을 올리려면 초대를 받아야 해요. 아래 3단계는 처음 한 번만 하면 돼요.

1. [github.com](https://github.com)에 들어가 오른쪽 위 **Sign up**을 눌러 가입해요. (이미 계정이 있다면 건너뛰어요.)
2. 내 **GitHub 아이디(username)**를 스터디장에게 보내요. 아이디는 로그인 후 오른쪽 위 프로필 사진을 눌러서 확인할 수 있어요.
3. 가입한 이메일로 온 **초대 메일**을 열고 **Accept invitation**을 눌러요.
    - 메일을 못 찾겠다면 [초대 확인 페이지](https://github.com/gdgclaude/AICE-associate-study/invitations)에 로그인한 상태로 들어가도 돼요.

초대를 수락하지 않으면 저장소를 볼 수는 있지만 파일을 올릴 수는 없어요.

## 매주 실습코드 올리는 방법

웹 브라우저만 있으면 돼요. 아래는 1주차를 예로 들었어요. 다른 주차는 `week1` 대신 그 주차 브랜치를 고르면 돼요.

1. **ipynb 파일 내려받기**
    - Colab: 메뉴 **파일 → 다운로드 → .ipynb 다운로드**
    - Jupyter: 메뉴 **File → Download**
    - 파일 이름은 `week1.ipynb`처럼 주차를 넣어 바꿔 주세요.
2. **저장소 들어가기**: GitHub에 로그인한 상태로 [스터디 저장소](https://github.com/gdgclaude/AICE-associate-study)에 들어가요.
3. **브랜치 바꾸기**: 파일 목록 왼쪽 위에 `main`이라고 적힌 버튼을 눌러요. 목록에서 `week1`을 고르면 버튼 글자가 `week1`로 바뀌어요.
4. **내 폴더 들어가기**: 파일 목록에서 내 이름 폴더(예: `선준`)를 눌러요.
5. **업로드 화면 열기**: 오른쪽 위 **Add file** → **Upload files**를 눌러요.
6. **파일 넣기**: 1번에서 받은 ipynb 파일을 화면에 끌어다 놓거나 **choose your files**를 눌러 골라요.
7. **저장(커밋)하기**: 아래 **Commit changes** 칸에 메모를 적어요 (예: `선준 1주차 실습`). **Commit directly to the week1 branch**가 선택된 걸 확인하고 초록색 **Commit changes** 버튼을 눌러요.
8. **확인하기**: 내 폴더에 파일이 보이면 끝이에요. 파일을 누르면 코드와 실행 결과가 그대로 보여요.

## 꼭 지켜 주세요

- **브랜치부터 확인해요.** 올리기 전에 왼쪽 위 버튼이 이번 주차(`week1`, `week2` …)인지 봐 주세요. 실수가 가장 많이 나는 부분이에요.
- **`main` 브랜치에는 올리지 않아요.** `main`은 스터디장이 관리해요.
- **내 폴더에만 올려요.** 다른 사람 폴더의 파일은 수정하거나 지우지 않아요.
- **파일 이름은 `week주차.ipynb`예요.** 예: `week3.ipynb`
- **비밀번호나 API 키는 지우고 올려요.** 이 저장소는 공개라서 누구나 볼 수 있어요.
- **`.gitkeep` 파일은 지우지 않아요.** 빈 폴더를 유지하려고 넣어 둔 빈 파일이에요.

## 자주 묻는 질문

**다른 사람 코드는 어떻게 봐요?**
저장소에서 브랜치를 그 주차로 바꾸고 보고 싶은 사람 폴더를 눌러요. ipynb 파일을 누르면 코드와 결과가 바로 보여요.

**올린 파일을 고치고 싶어요.**
고친 파일을 같은 이름으로 같은 자리에 다시 올리면 덮어써져요. 예전 버전도 기록에 남아서 걱정하지 않아도 돼요.

**이번 주차 브랜치가 목록에 없어요.**
주차 브랜치는 스터디장이 매주 만들어요. 아직 없다면 스터디장에게 알려 주세요. 직접 만들지는 않아요.

**Add file 버튼이 안 보여요.**
로그인을 하지 않았거나 초대를 아직 수락하지 않은 거예요. "처음 한 번만 하면 되는 준비"를 다시 확인해 주세요.

**잘못된 브랜치나 폴더에 올렸어요.**
당황하지 말고 스터디장에게 알려 주세요. 기록이 남아있어서 쉽게 되돌릴 수 있어요.

**"Propose changes"나 "Create a new branch"가 나왔어요.**
초대가 수락되지 않았거나 다른 옵션을 고른 거예요. **Commit directly to the week주차 branch**를 고르고, 그래도 안 되면 스터디장에게 물어봐 주세요.

## (선택) Git 명령어로 올리기

웹 업로드로 충분해요. Git을 연습해 보고 싶은 분만 [Git](https://git-scm.com/downloads)을 설치하고 터미널에서 아래 순서대로 입력하면 돼요.

처음 한 번만 저장소를 내 컴퓨터로 복사해요.

```bash
git clone https://github.com/gdgclaude/AICE-associate-study.git
cd AICE-associate-study
```

매주 아래처럼 올려요. `week1`과 `선준`은 주차와 내 이름으로 바꿔요.

```bash
git fetch                      # 새로 생긴 브랜치 가져오기
git switch week1               # 이번 주차 브랜치로 이동
git pull                       # 다른 사람이 올린 내용 받기
# 선준 폴더에 week1.ipynb 파일을 복사해 넣기
git add 선준/week1.ipynb
git commit -m "선준 1주차 실습"
git push
```

처음 `git push`를 하면 GitHub 로그인 창이 뜨고, 로그인하면 업로드돼요.
